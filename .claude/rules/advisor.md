## Rules — Advisor (`docs/advisor.md`)

- **A judgment layer, not a feature catalog**: one ambient surface answering *what would make this task easier right now* — observation · guidance · next move. The model judges the shape of help (`AdvisorMove`; `start` is not a move); the deterministic system stays authoritative through sensors (`StallDetector`/`BreakdownEligibility`/`DecisionShape` → FACT lines), the gate (`TaskCapabilities.advisorWorthy`, a cost heuristic) and the off-device fallback.
- **Rung 0 always has an answer** (`DeterministicReading`, shape-aware, additive, never restating the spine; the dependents arm yields to `.waiting`); `.timedOut`/`.failed` degrade to it; a floor reading is not an `offer`. External waits reach the facts. **Silence is a first-class judgment** (`.quiet(.gate)`/`.quiet(.model)`); `.quiet(.model)` renders as one muted bar line ("Looked just now — nothing to add."). The loop closes on `task.updatedAt` and `openedBlocker`. `TaskAdvisorGoldenTests` (injected judge) is the acceptance gate.
- **Every "ask Ezra" surface is ONE primitive — `AI/Inquiry.swift`**: scope → facts → floor or model → validate → at most one move. `TaskInquiryScope` and `HouseholdInquiryScope` are conformances (on-device only, grep-pinned; never act; revealed whole; `ThinkingLine` in the pending slot). The Advisor reading is a zero-turn inquiry (`mode: .reading`); `InquiryService` owns every on-device session plus one warm spare. Both chats open keyboard-DOWN when there is a reading to read. Cited rows carry the list's two swipes on both chats (`ChatCitationParityTests`). **A floor shape is added only on a transcript** — `HouseholdChatEval.probes` asks the model the closed questions the floor declines and prints what it said; the 2026-09-17 GA runs earned `.dueTomorrow`/`.dueNextWeek`/`.inProgress`/`.category`/`.stalest` and the done shape's past-tense vocabulary (the model listed tasks due today as "tomorrow", three unstarted tasks as "in progress", said Maya had finished nothing because finished work never enters the slice, and guessed "untouched longest" from due dates). **A blocked task brings its chain into the slice** (`completingChains`, both directions, inside the cap). **The session survives its own failures** (2026-09-17): a turn arriving while the abandoned loser is still generating, or one that overflows the window, moves the thread to a fresh `LanguageModelSession(profile:history:)` over the finished exchanges (metered in `InquiryService.rebuilds`); the profile's `.transcriptErrorHandlingPolicy(.revertTranscript)` keeps a failed turn out of the transcript a retry sees.
- **The facts fingerprint is the calm invariant**: same task + same meaningful context → same reading; `AdvisorRevealGate` refuses a second reveal per fingerprint; dismiss binds to it. **Model output is untrusted transport; `ValidatedReading` is the contract** (drops/degrades, never substitutes; options 2–4, steps 2–5, `openBlocker` needs a real blocker). Rung 1 is durable (`AdvisorReadingCache`, sidecar). Dismissals are `HumanVerdict`s (sidecar) and teach (`Learned`, threshold 2, cap 8 — the ONE learner over `HumanVerdicts.collect`).
- **Presentation:** ONE home — a single line in the pinned bar under the CTA (`TaskDetailView.advisorLine`) that opens the task chat, where the reading is the opener; moves run through `AdvisorActions`. The flagged decision's reason line and its button stay on the PAGE; that button reads **"I've decided"** (first person; the pinned CTA is imperative, a control reporting a reached state speaks as the human; alert confirm "Record"). The Advisor never wears `accentGradient`; the reading is containerless and label-less; a failed generation renders nothing; "Why this?" shows evidence, never reasoning (`userVisibleEvidence`, `workIntent` excluded). The Start tap earns a kickoff line (containers from `nextOpenStep`, deciding tasks none, else `KickoffService`).
- **The on-device reading is FITTED to the window, never sent blind** (2026-09-17, `TaskAdvisorService.fitted` · `TaskAdvisorFacts.TrimLevel`): the phone's `contextSize` is 4096, the prompt is counted with the model's own `tokenCount(for:)` against it minus the fixed overhead, and the ladder gives up related tasks → clipped quote/reasoning → clipped notes → bare facts; only the PROMPT is fitted (session key, validation and evidence read the original facts). **A context-overflow catch matches `AppBrain.errorLabel`, never a case** (`InquiryService.isContextOverflow`; the deprecated case never fired on GA). **The kickoff line passes `KickoffService.validated`** (a digit run, URL or email the facts never held drops the step), reads the capture words and the abandoned-start count, and adopts a spare warmed while Start is the CTA. **List fields are bounded at the decoder** (`.maximumCount`/`.range` on the reading's options, steps, minutes) — upper bounds only; the validator still clamps.
- **The router asks for a REASONING BUDGET** (`ReasoningBudget`: none/shallow/deep; `depthReason` `.decision` · `.multiStep` (blockers + open steps ≥ 2) · `.repeatedlyAbandoned` (`abandonedStarts >= 2`, in the FINGERPRINT)). Every depth reason must be reachable (`ReasoningBudgetTests.everyDepthReasonIsReachable`). `StallDetector` and the `.dying` headline read `recentAbandonedStarts` (windowed, silent while `.doing`); `StallDiagnosis.headline` takes both counts as REQUIRED parameters. **`InertSignalTests`** guards fields the app can no longer write (`deferralCount`, `carriedOverCount`) — prose may name a dead field, code may not read one; a fixture describing an unreachable state is worse than none.
- **Routing is DISCOVERED** (`-AdvisorBenchmark`: the strongest rung sets the ceiling, cheaper rungs earn cases by move equality, modal across `-AdvisorRepeats`, printing `OVER-CLAIMED`/`UNDER-CLAIMED`); the routing percentage is an output. **Depth is not length.** Latency is a budget per rung (`advisorSeconds(rung:presenceTime:)`: on-device 20s, precomputed deep 60s, presence-time deep 25s salvaging DOWN a rung). Deep judgments run off the open moment (`precompute`, `.shallow` skipped, half the daily cap) — **generated is not offered; SEEN is offered** (`Entry.pendingOffer`). The quality signal is progression LIFT against a judged-silence control (`AdvisorMetrics.progression(among:)`), never AI activity.
- **Every model call goes through one seam** (`ModelRun.perform`, `ModelDeadline`, `ModelResult` — the product vocabulary; `.unavailable`/`.cancelled` not retryable; cancellation keys on `isActive`). **`ModelDeadline.race` never awaits the loser** (2026-09-17): the model call is an unstructured detached task, the timer wins on the clock whatever the call does, and the primitive is `nonisolated` — a task-group race inherited the main actor and waited for its child, so a `respond` that ignored cancellation (the GA model wedged on one guided case) held every deadline hostage and the deterministic tail behind it; `ModelDeadlineTests.uncancellableOperationStillTimesOut` pins it. `ModelMetrics` records outcomes locally. **Rung 3 is a slot** (`CloudModel.provider`, ONE provider — Gemini via Firebase AI Logic, `gemini-3.7-flash`; `isAvailable` must never construct the model or touch the network; `isReachable` adds `CloudHealth`; `isReachable(for:)` adds the pillar's kill switch; a "high demand / try again later" answer is a REFUSAL that opens the breaker on the first call, whatever HTTP status it wears — Gemini 3.7 Flash sent it as 500 INTERNAL twice on 2026-09-17, the day the 12.19 bridge was first proven end to end from the phone). **One dumb daily cap** (`CloudBudget.dailyCallCap` 500, loud in DEBUG, silent to the user, not a governor). **Meter first** (`IntelligenceLedger`: rung × workload, `cloudCallsToday`, written where the routing decision lands; sweeps never reach the cloud rung).
